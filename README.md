
# AI Smart Study Planner

An intelligent study planning application developed using Python, Streamlit, TCP, UDP, and SQLite.

## Project Description

The AI Smart Study Planner helps students organize assignments, manage deadlines, monitor task completion, and generate study recommendations.

## Main Features

- Assignment management
- Automatic study plan generation
- Assignment priority analysis
- Task completion tracking
- TCP client-server communication
- UDP status messaging
- Network activity monitoring
- Persistent SQLite database storage

## Technologies Used

- Python
- Streamlit
- TCP and UDP sockets
- SQLite
- Pandas

## Agentic AI Workflow

The application uses a rule-based, tool-using agentic workflow to:

1. Retrieve assignments.
2. Analyze deadlines and priorities.
3. Rank pending tasks.
4. Generate study recommendations.
5. Save the generated study plan.

## How to Run

1. Install Python.
2. Create and activate a virtual environment.
3. Install the required packages.
4. Start the TCP server.
5. Start the UDP server.
6. Run the Streamlit application.

```bash
python -m streamlit run app.py
```
